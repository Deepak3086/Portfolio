# Portfolio

A single-page personal portfolio built with plain HTML only: no CSS, no JavaScript, no frameworks.

## About

This is the portfolio of **Deepak J G**, a third year Information Technology student and Full Stack Developer. The page covers my skills, internship experience, projects, education and contact links.

## Sections

- About
- Skills
- Experience
- Projects
- Education
- Contact

## Tech

- HTML5 (semantic tags: `header`, `nav`, `main`, `section`, `article`, `footer`)
- No CSS or JavaScript, so the browser's default styling applies

## Run locally

1. Clone the repo:
   ```bash
   git clone https://github.com/Deepak3086/portfolio.git
   ```
2. Open `index.html` in any browser.

## Use your own photo

Save your photo in the same folder as `profile.jpg`, then change the `src` of the `<img>` tag in `index.html` to `src="profile.jpg"`.

## Host with GitHub Pages

1. Go to **Settings → Pages** in the repo.
2. Under **Branch**, choose `main` and `/ (root)`, then save.
3. The site will be live at `https://deepak3086.github.io/portfolio/`.
